As Gaeilge

Gaeil

Teanga Ríomhchlárúcháin as Gaeilge

Gaeil is a programming language written in Irish (Gaeilge). You write code with Irish keywords such as scríobh, má, and feidhm; gaeil.py translates those keywords into Python and runs the program, so it works anywhere Python is available, including a phone in Termux.

Tosaigh anois Féach ar an stór fitzyracing1.com

Sampla beo

A terminal-style walkthrough of the real programs in examples/. The keywords, translations, and output match gaeil.py — nothing here is invented syntax.

Tosóidh an taispeántas cóid anseo.

Eochairfhocail

Every Irish keyword gaeil.py recognises, and the Python token it becomes. This table is Irish → English, taken from the translator’s KEYWORDS map.

Gaeil is otherwise ordinary Python, so names, numbers, punctuation, and indentation stay as they are.

Conas tosú

Clone the repository and run the hello example. You only need Python 3.

git clone https://github.com/fitzyracing1/Gaeil.git
cd Gaeil
python gaeil.py examples/hello.gaeil

The same command is the first program in the demo above. python gaeil.py with no file runs a short built-in demo from the translator.
