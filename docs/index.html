Teanga Ríomhchlárúcháin as Gaeilge

Write Python
in Irish.

Gaeil is a programming language written in Irish (Gaeilge). You write keywords such as scríobh, má, and feidhm. gaeil.py translates them into Python and runs the program — on a laptop, or on a phone in Termux.

Get started View the repository 
$ git clone https://github.com/fitzyracing1/Gaeil.git
cd Gaeil
python gaeil.py examples/hello.gaeil
examples/hello.gaeil

Why Gaeil

          
A small language with Irish keywords.

          
Gaeil is intentionally tiny: one translator file, a handful of examples, and the same Python you already have.

        

        

          

            

              
            

            
Fourteen Irish keywords

            
Familiar Python control flow, written as Gaeilge: scríobh, má, eile, fad, feidhm, and more.

          

          

            

              
            

            
A one-file translator

            
gaeil.py replaces those keywords with Python and runs the result. No extra toolchain is required.

          

          

            

              
            

            
Runs where Python runs

            
Use it on a desktop or in Termux on a phone. If you can run python, you can run Gaeil.

          

          

            

              
            

            
Try it in the browser

            
The playground translates Gaeil to Python and runs it with Pyodide. The runtime is loaded only when you press Run.

Quick start

          
Three steps to a running program.

          
Gaeil programs use the .gaeil extension. The only .py file you need is the translator.

        

        

          

            
Clone the repository

            
Get the translator and the examples from GitHub.

            
git clone https://github.com/fitzyracing1/Gaeil.git
cd Gaeil

          

          

            
Run an example

            
Point gaeil.py at a .gaeil file. This prints the translation, then the program output.

            
python gaeil.py examples/hello.gaeil

          

          

            
Write your own

            
Use the Irish keywords from the reference below. Any other syntax is ordinary Python.

            
python gaeil.py my_program.gaeil

          

        

      

    


    

      

        

          
Tools

          
Helpers around the language.

          
Gaeil itself stays a small translator. Helpers live in their own repositories.

        

        

          

            
gaeil-tidy

            
Turns rough, mixed-style notes into runnable Gaeil. It lowercases keywords, converts C-style braces and comments, expands i++, and reports every change. The original file is never overwritten.

            

              View gaeil-tidy
            

          

          

            
$ pipx install git+https://github.com/fitzyracing1/gaeil-tidy
