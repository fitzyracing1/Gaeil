Cad é Gaeil?

Gaeil is a simple programming language that uses Irish (Gaeilge) keywords. It is designed so Irish speakers and learners can write code in their own language.

Eochairfhocail (Keywords)

EnglishGaeil
printscríobh

elseeile

True / Falsefíor / bréag
and / or / notagus / nó / ní

Sampla

scríobh("Dia duit, a dhomhan!")

feidhm factorial(n):
    má n <= 1:
        fill 1
    eile:
        fill n * factorial(n - 1)

scríobh(factorial(5))
